# Inter

Runtime fonts come from @expo-google-fonts/inter 0.4.2 (400Regular, 600SemiBold, 700Bold subpaths only). Inter-LICENSE_FONT.txt records the SIL Open Font License, and Inter-LICENSE.txt records the package license. The Figma pack deliberately includes no font binaries.

The root useFonts gate blocks routes until all three weights load. Every supplied typography style maps to its exact size and weight. No line height or tracking was invented because the handoff does not specify them. The old template SpaceMono file is unused.
