## 1. Execution Guardrails (Mandatory Across All Sprints)

1. **Sprint 00B Gate Before Screen Work:** Complete shared design-system primitives, official icon exports (`4:3`), typography line-height alignment, and role navigation bar icons (`Sprint 00B`) before starting `Sprint 01` screen implementation (`AGENTS.md`).
2. **Exact Node Inspection Before Coding:** Before implementing any screen or component, inspect its exact Figma node ID via `get_design_context` and verify static assets. Never invent tokens, colors, icons, or branding.
3. **Thin Routes & Shared Composition:** Keep Expo Router files in `app/` thin (route parameters and screen composition only). Place feature logic, Zod schemas, TanStack Query hooks, and screens under `src/features/<feature>/` and reusable primitives under `src/components/`.
4. **No Fabricated Data or Credentials:** Specimen values shown in Figma (`$8,230.00`, `$12,480`, `Oak Street Supply`, `Acme Services`) are layout specimens only (`468:237`). Bind all product screens to Zod-validated API contracts (`getValidated`) with `queryKeys.resource(session, resource)`. Keep credentials in `expo-secure-store` (`src/lib/storage/credentials.ts`) and clear/cancel queries on session or business switches (`resetRemoteState()`).
5. **Four Mandatory UI States:** Every screen and feature must implement **loading**, **empty**, **error**, and **access-denied (forbidden)** states matching Figma `STATE` and `REFERENCE` specifications.
6. **Policy & Localization Gates (`D01`–`D12`):** Do not ship `POLICY-BLOCKED` Pro+ flows (`304:975`), `PLAN PREVIEW` billing mockups (`502:1622`, `513:1748`, `523:1922`, `536:1953`, `523:3107`, `523:3885`), or provisional Spanish (`es-US`) screens until client decisions `D01`–`D12` are formally approved.
7. **Verification Gate:** Run `pnpm check` (`pnpm typecheck && pnpm lint && pnpm test`), `pnpm run doctor`, and Expo export checks after every sprint.
